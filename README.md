# Психологический блог YouTalk

Верстка блога для проекта YouTalk. Адаптив, семантика, чистота кода — всё по макету из Figma.

## Что внутри

- Лента статей с фильтром по тегам
- Страница конкретной статьи (на примере «Как не утонуть в тревоге»)
- Шапка (TopBar), подвал (BottomBar), хлебные крошки и боковая колонка (RightPanel)
- Карточки материалов с картинками, авторами, датами
- Адаптив: десктоп, планшет, телефон — всё подстраивается
- Интерактив: ховеры, фокусы, курсор-поинтер на всех кнопках и ссылках

## Технологии

- React (на функциональных компонентах)
- Vite — быстрая сборка
- Чистый CSS (без препроцессоров, но с медиазапросами)
- ESLint для порядка в коде

## Структура проекта

```text
src/
  components/        Переиспользуемые UI-блоки
    TopBar.jsx
    BottomBar.jsx
    Breadcrumbs.jsx
    TagList.jsx
    PostItem.jsx
    RightPanel.jsx
    Icon.jsx

  pages/             Страницы приложения
    BlogPage.jsx
    ArticlePage.jsx

  data/              Данные и импорты ассетов
    blogContent.js
    articlePics.js

  assets/youtalk/    Локальные изображения и SVG
  App.jsx            Выбор страницы по текущему URL
  main.jsx           Точка входа React
  index.css          Глобальные стили и адаптив
```

## Как запустить

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

После этого проект доступен по адресу:

```text
http://localhost:5173/
```

Чтобы посмотреть страницу статьи:

```text
http://localhost:5173/article
```

## Проверка на телефоне

Если телефон и компьютер находятся в одной Wi-Fi сети, можно открыть проект с телефона

Узнать локальный IP на macOS:

```bash
ipconfig getifaddr en0
```

Запустить Vite для доступа с других устройств в локальной сети:

```bash
npm run dev -- --host 0.0.0.0
```

На телефоне открыть адрес, который появится в терминале, например:

```text
http://192.168.0.121:5173/
```

Если порт `5173` занят, Vite может предложить другой порт, например `5174`.
